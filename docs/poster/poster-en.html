USB checking station

Check here every USB key before using it on a work computer.

How to use it

1
Insert your key The analysis starts automatically. No button to press.
2
Do not remove the key The screen shows the time left. If it is long, it tells you when to come back.
3
Read the color The screen turns green, orange or red. Follow the instruction below.

The result

✓GREEN

"Aucune menace détectée" (no threat found)

You can remove and use your key.

!ORANGE

"Clé vérifiée, avec des avertissements" (key checked, with warnings)

You can use it, but be careful.

Read the message on screen (for example: several partitions).

✕RED

"N'utilisez pas cette clé" (do not use this key)

Do not plug it into any computer. Bring it to your IT support.

Also red when the key could not be fully checked (file protected by a password, key that can start a computer...).

Good to know

  • Key removed before the end = red: it has not been checked. Insert it again to restart the analysis.
  • The station does not clean the key: it never deletes, changes or adds any file on your key.
  • A green result does not replace caution: do not open unexpected files, do not enable the macros of a document.
  • USB key found by chance: do not plug it in anywhere, bring it to your IT support.
  • "Station hors service" screen (out of service): do not use the station and tell your IT support.
